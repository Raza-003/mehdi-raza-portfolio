# Mehndi Raza — Developer Portfolio

A responsive, mobile-app-inspired developer portfolio built with **Next.js App Router, TypeScript, Tailwind CSS v4, and Motion**.

The portfolio showcases my development experience, technical skills, selected projects, and professional background through an interactive, mobile-inspired interface.

## ✨ Features

- Responsive design for desktop, tablet, and mobile.
- Mobile-app-inspired portfolio experience.
- Interactive project overview modals.
- Project details, technology stacks, and screenshots.
- Skills and professional experience sections.
- Smooth animations powered by Motion.
- Dark and light theme support.
- Contact options for professional inquiries.
- Resume download section.

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4 and custom CSS
- **Animations:** Motion
- **Icons:** Lucide React

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project

```bash
cd YOUR_PROJECT_FOLDER
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## ⚙️ Before Publishing

Review and update the following details before making the portfolio public:

1. Replace the placeholder email `hello@mehindiraza.dev` with your professional email.
2. Update GitHub and LinkedIn profile URLs in `src/components/portfolio-home.tsx`.
3. Add your latest resume PDF inside `public/resume/` and connect the download action.
4. Add verified project screenshots, repository links, and app-store or demo links.
5. Verify all project descriptions, metrics, and experience dates against your actual experience and resume.
6. Add your professional profile photo if you want to replace the default MR monogram.

## 📌 Project Notes

- Project cards currently open an overview modal.
- No fabricated live demos or repository links are included.
- Project descriptions and metrics are editable starter content and should be verified before sharing.
- Motion animations respect the user's reduced-motion preference through CSS.
- Keep environment variables and private credentials out of the public repository.
